# Grill With Docs

Use this skill to conduct thorough requirements alignment:
1. Interview the user on architectural decisions, ambiguities, and edge cases.
2. Record resolved terminology in `GLOSSARY.md`.
3. Document project context and scope boundaries in `CONTEXT.md`.
4. Capture design choices as numbered Architecture Decision Records in `ADR.md`.
5. Update the technical implementation plan before proceeding to code generation.
